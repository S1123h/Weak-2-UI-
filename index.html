Accessible FAQ Accordion

A reusable, keyboard-friendly accordion for FAQs, product details, and settings panels. It supports single- or multi-open behavior, smooth height transitions, and graceful fallbacks.

Frequently asked questions

An accordion is a vertically stacked set of expandable sections. It helps users scan content quickly while keeping less-important details hidden until needed.

Press Tab to reach an accordion header, then use Enter or Space to expand or collapse it. Use Arrow Up and Arrow Down to move between headers, Home for the first header, and End for the last.

Yes. This component supports two modes. Set data-accordion-mode="single" to allow only one open panel, or data-accordion-mode="multiple" to let users open several panels at once.

The component uses a progressive-enhancement fallback. If JavaScript cannot run, all panels are displayed in an expanded, readable state and the buttons are disabled, so no content is lost.
